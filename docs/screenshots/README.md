## Screenshot rules

- 使用无敏感信息的账号或公开页面。
- 不显示 Cookie、二维码、私信、历史记录、动态草稿或个人推荐中的隐私内容。
- 截图前关闭浏览器开发者工具、扩展管理页和本地路径信息。
- 图片应放在本目录，并在 README 或对应文档中配上页面名称和当前状态说明。
- 如果截图只展示本地演示数据，应明确标注“本地演示”，不要让读者误以为是线上接口固定返回。
